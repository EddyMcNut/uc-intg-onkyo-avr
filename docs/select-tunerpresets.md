# Select Tuner Preset

As from v0.9.6 this integration offers a 'select' entity for Tuner Presets.

![](./../screenshots/select.png)

This entity will offer a drop down of the stations names of your Tuner Presets, for example `Sublime`, `Joe`, `4ever49`.

It also acts as a Sensor, showing the current selected Preset.

If your AVR does not support the delivery of the preset list, the select entity will be empty.

If not needed, you can disable this Select entity during (re)configuration of the integration, a reboot of your remote is needed to see the effect:

![](./../screenshots/select-tuner-preset.png)
